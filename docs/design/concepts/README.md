# Концепты интерфейсов (#44)

Концепт-арты нового UI, одобренные владельцем 2026-11-17. Данные на картинках выдуманные, серые блоки — условная страница hh.ru. Исходники — HTML: правка и перерисовка в PNG (Edge или Chrome, без зависимостей):

```bash
msedge --headless=new --hide-scrollbars --window-size=1600,1380 --screenshot=extension.png extension.html
msedge --headless=new --hide-scrollbars --window-size=1600,1000 --screenshot=web.png web.html
```

## Визуальный стиль (одобрен)
Как шапка GitHub-профиля владельца и логотип Telegram-бота: тёмный фон `#0d1117` с точечной сеткой `#1a222d`, рамки `#263040`, текст `#e6edf3`, приглушённый `#7d8a99`, акцент `#f0a3a8`, успех `#7ee2a8`; моноширинный шрифт (Cascadia Mono) — для чисел, меток и журнала, остальное — системный sans.

## Расширение — `extension.png` (#123)
- **Выбран вариант A — плавающая панель.** Действия по странице: на выдаче — «Отправить в поиск «…»» и сводка очереди с сервера; на «Чатах» — «Синхронизировать чаты с сервером» и галочка «спасибо» на отказы; в свёрнутом виде — плашка в углу, hh.ru не закрывает.
- Вариант B (боковая панель Chrome) — для сравнения, не выбран.
- Настройки — отдельной страницей расширения.

## Веб — `web.png` (#120, #121)
- **Дашборд:** период 7/30/90 дней; **статистика по агрегаторам раздельно** (hh.ru; hirify, getmatch — после подключения, #32), «Все» — сводно; ключевые числа; воронка с выравниванием полос по сетке и процентом от предыдущего шага; отклики по дням — отправлено / ответили / приглашение и собеседование; таблица по поискам выбранного агрегатора.
