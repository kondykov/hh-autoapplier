4. Современный UI: общие приёмыДля всех разделов, не только LLM

Команды по Ctrl+K — переход в раздел, поиск вакансии по названию, «запустить сбор», «проверить LLM».
Отмена вместо подтверждений. «Скрыть», «Отклонить», «Отозвать» — сразу, с тостом «Отменить» 6 с:
✓ 2 вакансии возвращены в очередь Отменить
Клавиши в «Проверке» и «Отсеве»: J/K — следующая/предыдущая, A — одобрить, R — отклонить, X — выбрать.
Скелетоны при загрузке вместо пустого экрана; относительное время («2 ч назад», точное — при наведении).
Иконки — один набор SVG (вместо символов ◫ ✎ ✉), подписи остаются.
Пустые состояния с действием: «Отсеянных нет — LLM оценивает строже? Настроить порог».
Фильтры в адресе — ссылку на отфильтрованный список можно сохранить и открыть с телефона.
Без фреймворков и сборки (решение #120); иконки — встроенный SVG-спрайт.
