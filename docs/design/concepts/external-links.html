Не уведомляем

hh.ru и его домены; ссылки в отказах; сайт компании «для знакомства»; ссылки, о которых LLM говорит «действий не нужно».

Безопасность

Адрес — только из текста сообщения: LLM не может подставить свой (принимаются лишь найденные сервером). Показываем домен крупно, предупреждаем о незнакомых доменах, сокращателях и http. Ничего не открываем и не заполняем автоматически.
