# Инструкция пользователя

Как поставить и каждый день пользоваться hh-autoapplier. Для разработчиков — [ARCHITECTURE.md](ARCHITECTURE.md), [BACKEND.md](BACKEND.md), API — `/scalar` на сервере.

## Что это и чего ждать

Полуавтоматические отклики на hh.ru:

1. **Сервер** (backend) раз в час собирает вакансии по вашим поискам с публичных страниц hh.ru и отбирает их по правилам.
2. **LLM** (по умолчанию Groq) оценивает каждую прошедшую правила вакансию под ваши резюме: подходит, сомнительно, не подходит. Подходящим пишет сопроводительное письмо, отвечает на анкеты работодателей.
3. **Вы** проверяете сомнительные: в веб-интерфейсе (раздел «Проверка») или кнопками в Telegram.
4. **Расширение** в браузере откликается на одобренные вакансии из очереди сервера: выбирает резюме, вставляет письмо и ответы анкеты, нажимает «Отправить».
5. **Ответы работодателей** расширение забирает из чатов hh.ru по кнопке «Синхронизировать чаты»: статусы откликов, разбор приглашений и вопросов с черновиком ответа.

Риски: аккаунт hh.ru настоящий. Частые действия ведут к капче и блокировке; капчу инструмент не обходит — встаёт на паузу и ждёт вас. Автоматизация может противоречить условиям hh.ru: пользуйтесь умеренно. Программа предоставляется «как есть», автор не отвечает за блокировку аккаунта, отправленные отклики и письма, потерю данных и расходы на LLM — подробно в [README](../README.md#отказ-от-ответственности).

## Установка

### Сервер

Нужен [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```powershell
cd server
copy .env.example .env
```

В `server/.env` задайте:

| Параметр | Что это |
|---|---|
| `POSTGRES_PASSWORD` | пароль базы — любой длинный |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | первый администратор (вы); пароль от 10 символов. После первого запуска смените пароль и очистите `ADMIN_PASSWORD` — в файле он лежит открытым текстом |
| `LLM_API_KEY` | ключ Groq: https://console.groq.com/keys (бесплатный тариф). Пусто — LLM выключена, вакансии идут в очередь по одним правилам |
| `LLM_DAILY_LIMIT` | сколько запросов к LLM в сутки (по умолчанию 300) |
| `LLM_USER_DAILY_LIMIT` | доля одного пользователя в этом лимите (по умолчанию 150, 0 — без доли); сверх неё его вакансии ждут следующих суток |
| `TELEGRAM_BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather); пусто — без Telegram |
| `COLLECT_INTERVAL_MINUTES` | как часто собирать вакансии (по умолчанию 60) |
| `COLLECT_MAX_PAGES` | сколько страниц выдачи листать на поиск за проход, по 50 вакансий (по умолчанию 20) |

```powershell
docker compose up -d --build
```

Проверка: http://127.0.0.1:8080/health отвечает `{"status":"ok"}`. Сервер слушает только этот компьютер (`127.0.0.1`).

### Расширение

```powershell
npm install
npm run build
```

Без сборки: скачайте `hh-autoapplier-<версия>.zip` из [релиза расширения](https://github.com/kondykov/hh-autoapplier/releases/latest) и распакуйте — это та же папка `dist` с письмом по умолчанию. При обновлении распакуйте новую версию в ту же папку и нажмите «Обновить» на `chrome://extensions`.

Загрузите папку `dist` в Chrome: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное». Или запустите тестовый браузер с расширением: `node scripts/dev-browser.mjs`. Войдите в hh.ru в этом браузере.

Панель расширения открывается **значком расширения** на панели Chrome — это боковая панель браузера: она не закрывает hh.ru и показывает действия для открытой вкладки. В шапке — версия расширения (например, `v0.8.0`), индикатор связи с сервером (точка и версия сервера; нажатие — «Проверить связь») и ⚙ — настройки. Под шапкой переключатель вида: **«Боковая»**, **«Плавающая»** (панель поверх страницы, перетаскивается за шапку) и **«Плашка»** (свёрнутая плашка в правом нижнем углу, раскрывается по клику); выбор запоминается, действия везде одни и те же. После `npm run build` браузер нужно перезапустить — по версии видно, загрузилась ли новая сборка.

Что показывает панель:

- на выдаче — «Отправить страницу в поиск «…»» и очередь;
- на вакансии и форме отклика — очередь: запуск и остановка, пробный режим, прогресс за запуск, дневной лимит, сводка очереди с сервера;
- на «Откликах» и чатах — «Синхронизировать чаты с сервером»; там же свёрнуты «Старые инструменты» («Next Отказ», «Авто-отказ»);
- «Синхронизировать чаты» есть и на других страницах: панель сама откроет «Отклики» hh.ru и запустит сбор;
- журнал внизу — сворачивается, хранит последние 50 строк.

Своё письмо по умолчанию (если сервер не прислал письмо LLM) можно положить в `letter.local.txt` до сборки — в git он не попадает — или вписать в настройках расширения.

## Первая настройка

Откройте веб-интерфейс http://127.0.0.1:8080/ и войдите email и паролем. Разделы: «Дашборд» (воронка, отклики и блок «Требует внимания»), «Проверка» (сомнительные: одобрить с правкой письма или отклонить), «Ответы» (ответы работодателей: разбор и черновики), «Вакансии» (списки с фильтром и историей), «LLM» (пока работает подвкладка «Мои модели», на телефоне раздел — в «Ещё»), «Поиски», «Кандидат» (профиль кандидата и профили резюме), у администратора — «Система» (пользователи, ручной запуск сбора и LLM). Меню под именем в шапке (на телефоне — в «Ещё»): пароль, токены расширения, Telegram, отчёт CSV, тема, выход и выбор «Данные:», чтобы посмотреть чужие данные (только просмотр). Всё то же доступно через API в `/scalar` (http://127.0.0.1:8080/scalar) — ниже указаны запросы для справки.

### Связь расширения с сервером

Настройки расширения (⚙ в панели или «Параметры» на `chrome://extensions`) → «Сервер»: адрес `http://127.0.0.1:8080` и токен, затем «Сохранить». Выпустите личный токен: «Профиль» → «Токены расширения» (или `POST /api/tokens` `{"name": "браузер"}` после входа по паролю) — значение `hh_…` показывается один раз, вставьте его в поле «Токен». «Проверить связь» — рядом с адресом появится «на связи» и версия сервера; адрес в домашней сети разрешите кнопкой «Разрешить доступ» там же.

### Резюме

`PUT /api/resumes` — по профилю на каждое ваше резюме на hh.ru:

- `name` — короткое имя (`.NET`);
- `match` — часть названия резюме на hh.ru, по ней расширение выберет его в форме отклика;
- `keywords` — направления (для правил);
- `summary` — опыт и навыки своими словами: LLM берёт факты **только** отсюда. Чего нет в `summary`, того не будет в письмах и ответах — пишите конкретно (стек, годы, проекты), без преувеличений;
- `letterTemplate` — шаблон письма: приветствие, подпись и контакты LLM сохранит дословно, середину напишет под вакансию.

### Профиль кандидата

Веб-интерфейс → «Резюме» → «Профиль кандидата» (или `PUT /api/profile`) — один на все резюме: общая часть (уровень, стаж, формат, город, языки, пожелания) и факты по навыкам — навык → где применял, сколько, что делал, цифры (синонимы через «/»: «EF Core / Entity Framework»). Под каждую вакансию LLM получает общую часть и факты только по навыкам этой вакансии: письма и ответы анкет точнее, а оценка реже отклоняет за «нет опыта X», если опыт описан. Пишите только то, что было, — это уходит работодателю от вашего имени.

На hh.ru у резюме должна быть видимость «Видно всем работодателям, зарегистрированным на hh.ru», иначе на часть вакансий не откликнуться.

### Поиски

`PUT /api/searches`, например:

```json
{"name": "dotnet", "query": "C# .NET", "area": "113", "extraParams": "work_format=REMOTE",
 "rules": {"excludeKeywords": ["junior", "1С"], "minSalaryRub": 200000, "allowedFormats": ["удалённо"]}}
```

Правила (`rules`): `includeKeywords` — нужно хотя бы одно из слов, `excludeKeywords` — ни одного; `allowedFormats` — допустимые форматы работы (часть текста формата на hh.ru: «удалённо», «гибрид»); `minSalaryRub`, `requireSalary` — зарплата; `skipWithTest` — пропускать вакансии с тестовым заданием; `minScore` — порог балла; `skipReview` — сомнительные по LLM сразу в очередь, без ручной проверки.

### Telegram

Если бот настроен: после входа по паролю `POST /api/telegram/link` (или «Профиль» → Telegram) → ссылка на бота с кодом (15 минут) → откройте её или отправьте боту `/start <код>`. `/stop` — отвязать чат (бот спросит подтверждение).

**Бот — один экран.** Это одно сообщение с кнопками: нажатия перерисовывают его на месте, новых сообщений нет, подтверждения всплывают сверху. `/menu` (кнопка «/» у поля ввода) присылает экран заново внизу чата. Разделы:

- **📝 Проверка** (`/review`) — одна карточка: вердикт LLM, стек, анкета, просьбы к письму, письмо. «Одобрить» и «Отклонить» — экран сам переходит к следующей («осталось 7»); «С причиной», «📄 Описание», «Следующая →». Просьбы к письму: «🔑 Вставить слово «…»», «👤 Подставить из профиля».
- **Ответы анкеты:** кнопка на каждый вопрос («✏️ Ответ N»; больше трёх вопросов — одна «✏️ Анкета (N)» со списком). Вопрос с одним вариантом — варианты кнопками, нажатие ставит выбор; с несколькими — галочки и «Готово»; текстовый — как письмо. Правки копятся вместе с письмом до «Одобрить с этим письмом».
- **Правка письма:** «✏️ Письмо» (или «✏️ Ответ N» для текстового ответа) — экран покажет текущий текст (нажмите на блок, чтобы скопировать) и будет ждать новый. Напишите его **обычным сообщением** — бот заберёт текст и уберёт его из чата, карточка покажет правку и «Одобрить с этим письмом» / «Отменить правку». Правка хранится, пока вы её не одобрите или не отмените. Экран ждёт текст 30 минут; «Отменить» — вернуться без правки. Так же пишется причина отказа и пропуска.
- **💬 Ответы** (`/dialogs`) — приглашения и вопросы работодателей: суть, текст, черновик ответа (нажмите — скопируется), «💬 Открыть чат», «✔ Обработано»; «Показать все» — с обработанными и отказами.
- **📊 Обзор** (`/overview`) — счётчики по статусам (нажмите — откроется список), «что дальше», «📄 Отчёт CSV» — файлом.
- **📋 Вакансии** (`/vacancies`) — выбор статуса и поиска, список с листанием «← →», карточка: «В очередь», «Оценить заново», «Скрыть»/«Вернуть», «Пропустить» (и «С причиной»).
- **🔎 Поиски** — включить и выключить поиск. **🛠 Сбор** (администратор) — состояние и «Запустить сейчас».

**Уведомления.** Важное приходит отдельным коротким сообщением со звуком: капча, нет входа в hh.ru, дневной лимит, ответ работодателя (кнопки «Открыть чат», «Обработано», «Подробнее»), сбои у администратора («✔ Понятно» убирает сообщение). Новые отклики на проверке и анкеты без ответа LLM собираются в одну **сводку** «🔔 Новое»: бот дописывает в неё строки без нового звука; кнопки «📝 Проверка (N)» и «💬 Ответы (M)» открывают экран. Открыли сводку или прошло 6 часов — следующее событие начнёт новую.

**Если бот молчал из-за связи** (сервер ходит в Telegram через VPN): уведомления не теряются. Когда связь вернётся, важные придут по одному, а обычные — одним сообщением «📭 Пока не было связи» со временем каждого. Уведомления старше суток не досылаются. Администратор видит состояние связи и журнал сбоев в `GET /api/health/links`.

Только в веб-интерфейсе: резюме и профиль кандидата, правила поисков, пароль, токены расширения, пользователи и чужие данные.

## Каждый день

### Сбор и оценка

Сервер собирает вакансии сам, раз в интервал. Оценка LLM, письма и ответы на анкеты идут в течение минуты после появления новых вакансий. Если вы нашли выдачу на hh.ru вручную — кнопка **«Отправить страницу в поиск «…»»** на странице поиска отправит её карточки в поиск, указанный в настройках расширения («Поиск для выдачи»).

### Проверка сомнительных

Telegram: новые отклики — строками в сводку «🔔 Новое», решать — «📝 Проверка» по одной карточке (`/review`). Письмо и ответы анкеты можно поправить и в боте («✏️ Письмо», затем текст обычным сообщением), и в разделе «Проверка» на http://127.0.0.1:8080/: там ответ с одним вариантом — списком, с несколькими — галочками.

### Пропущенные, с ошибкой, лишние в очереди

Веб-интерфейс → «Вакансии» (или пункты на «Обзоре»): у пропущенных (отказ LLM, стоп-слово, ваше решение) и упавших — кнопка «В очередь»; у ожидающих (в очереди, ждёт оценки, анкета) — «Пропустить» с необязательной причиной. Отклик, который ушёл на hh.ru без подтверждения, сервер отмечает «ошибкой» с причиной — прежде чем вернуть такой в очередь, проверьте на hh.ru, не отправлен ли он.

### Своя модель LLM для задачи

Веб-интерфейс → «LLM» → «Мои модели» (или `GET/PUT /api/profile/llm`): для каждой задачи — оценка вакансий, письма, анкеты, ответы работодателям — выберите подключение сервера или «как на сервере». Рядом — остаток дневного лимита подключения или «пауза до …», если провайдер ограничил запросы. Выбор действует только на ваши отклики. Подключения задаёт администратор на сервере (`server/llm-providers.env`, см. `docs/DEPLOY.md`); если подключение потом уберут, задача пойдёт «как на сервере».

Разово другой моделью: у отсеянной вакансии в «Вакансиях» — «Оценить заново через ▾». Вакансия проходит правила и сразу оценивается выбранным подключением; письмо потом пишется вашей обычной моделью, настройка «Мои модели» не меняется. Если провайдер не ответил, вакансия ждёт обычной оценки.

### Отклики из очереди

1. Кнопка **«Запустить очередь»** в панели. По умолчанию включён **пробный режим** (галочка): расширение заполняет форму, но «Отправить» не нажимает — проверьте резюме, письмо и анкету.
2. Для настоящих откликов снимите галочку пробного режима (панель переспросит). Задайте в настройках **«Откликов за запуск»** — после стольких очередь остановится сама (0 — без ограничения).
3. Остановить в любой момент — «Остановить очередь». Дневной лимит откликов — «Дневной лимит» в настройках.

Анкеты: если у вакансии анкета без готовых ответов, расширение отправит вопросы на сервер, LLM ответит (обычно за минуту), и вакансия вернётся в очередь. Если в анкете есть вопросы со свободным ответом, вакансия сначала попадёт в «Проверку»: там видны ответы LLM, их можно поправить перед «Одобрить» (галочка поиска «Без ручной проверки» пропускает этот шаг). Ответ с цифрами, которых нет в резюме и профиле, или с зарплатой не в вопросе о ней идёт на проверку всегда.

### Ответы работодателей

Кнопка **«Синхронизировать чаты с сервером»** (на «Откликах» и в чатах hh.ru; с другой страницы панель сама откроет «Отклики»):

- статусы откликов на сервере обновятся (отказ, приглашение);
- приглашения и вопросы работодателей LLM разберёт и предложит ответ — в Telegram (`/dialogs`: черновик копируется нажатием, «Открыть чат», «Обработано») и в разделе «Ответы работодателей» на http://127.0.0.1:8080/ («Копировать и открыть чат», «Обработано»). Отвечаете вы сами, поправив `[заглушки]`;
- на новые отказы расширение отправит текст из настройки «Ответ на отказ», если там стоит галочка «Отвечать «спасибо»» — только там, где hh.ru разрешает писать (обычно после отказа переписка закрыта). В пробном режиме ничего не отправляется.

### Отчёт

Веб-интерфейс → «Профиль» → «Скачать отчёт по откликам (CSV)» (или `GET /api/report?format=csv`) — все отклики на сервере.

## Безопасность

- `server/.env` и токены никому не показывайте и не коммитьте. Утёк токен — отзовите: `DELETE /api/tokens/{id}`.
- Сервер доступен только с этого компьютера. Доступ снаружи — только через VPN (планируется, #6), портов в интернет не открывать.
- Расширение не вводит ваши пароли и не решает капчу.

## Проблемы

| Что видно | Что делать |
|---|---|
| «Капча: работа на паузе» | Решите капчу в браузере — расширение продолжит само. Сделайте перерыв: капча — знак слишком частых действий |
| «Поменяйте видимость резюме» | В настройках резюме на hh.ru — «Видно всем работодателям, зарегистрированным на hh.ru» |
| «Сервер недоступен» в панели | Запущен ли Docker и `docker compose up -d`; адрес в настройках расширения — `http://127.0.0.1:8080` |
| «Неверный токен», «токен?» в шапке панели | Токен в настройках отозван, с опечаткой или от другого сервера; выпустите новый (`POST /api/tokens`) |
| «Очередь пуста» | Нет одобренных вакансий: дождитесь сбора и оценки, проверьте сомнительные в разделе «Проверка», расширьте поиск |
| LLM не пишет письма | `LLM_API_KEY` пуст или исчерпан дневной лимит (`LLM_DAILY_LIMIT`) — администратору придёт сообщение в Telegram; продолжится сама на следующие сутки |
| «Форма отклика не открылась» | Вакансия в архиве или ведёт на сайт работодателя — она помечается неудачной, очередь идёт дальше |
| Новая версия расширения не видна | Перезапустите браузер после `npm run build` и сверьте версию в шапке панели |
