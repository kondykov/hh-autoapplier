Настройки

Сервер

Выпустить — веб-интерфейс сервера, «Профиль». Пусто — оставить сохранённый.
Chrome пускает расширение только на разрешённые адреса: 127.0.0.1 и localhost — сразу, адрес в домашней сети — этой кнопкой.
Куда уходит страница выдачи по кнопке «Отправить страницу в поиск».

Очередь

0 — без ограничения. Пробный режим включается и выключается в панели.

Тексты

Уходит только туда, где hh.ru разрешает писать; в пробном режиме не отправляется.

Панель

Боковая открывается значком расширения. Переключатель есть и в шапке панели.
